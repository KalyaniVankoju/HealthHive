# 🏥 HEALTHHIVE – SMART HEALTH TRACKING & WELLNESS ASSISTANT

## 📌 PROJECT OVERVIEW

HealthHive is a comprehensive Android health and wellness application developed using Kotlin and Jetpack Compose. The application combines fitness tracking, hydration monitoring, BMI analysis, medicine reminders, personalized health recommendations, hair and skin care assistance, diet planning, analytics dashboards, and an AI-powered health chatbot into a single smart platform.

The goal of HealthHive is to help users build healthier habits through intelligent tracking, reminders, data visualization, and actionable wellness insights.

---

# 🎯 OBJECTIVES

3. Allow Gradle Sync to complete.
4. Connect an Android device or emulator.
5. Click **Run ▶️** to launch the application.
